# Vector Code Companion

I'm building a production grade fully functional code summariser web app which will summarise the code given to it using local models. The inputs of the app are through files, GitHub, watched files etc. I want u to build the production ready frontend of the project, which will look similar to chatgpt. The name of the project is vector. When the user opens the app the name and logo should be shown with a loading bar. After the loading bar completes, chatgpt like interface which is text input at bottom with + symbol to add files, links, photos, etc. should be there. On the left side, there should be options like past summaries, downloaded summary files, search option to search by word, and settings for toggling light/dark mode and giving system prompt. The user can change model in this app hence give an option to change models below the text input. On the right side, I want the user to be able to see all the input files or links he has provided.
